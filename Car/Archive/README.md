# Earlier car experiments

These programs are historical, not the current integrated robot configuration.

- `Pico_W/l298n_motor_test`: earlier Pico wheel test. The current wheels use Uno.
- `Pico_W/wireless_robot_link`: earlier car-side Pico/I2C bridge. The current
  car-side radio is FireBeetle ESP32; Pico now sits beside the laptop.
- `Pico_W/pico_w_test`: standalone LED/USB exercise.
- Pre-existing board backups remain local and ignored. They are not GitHub assets.

Do not flash an archived test over a current board merely to open its console.
